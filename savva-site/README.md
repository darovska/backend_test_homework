# Старый адрес семейного дашборда

Этот каталог больше не содержит Google OAuth и Google Sheets API.
Старая общедоступная ссылка автоматически перенаправляет на новый дневник:

https://savva-family-live.onrender.com/

Рабочее приложение находится в ../savva-app/: сайт и сервер на Render, семейный пароль, одна общая PostgreSQL.
Начальные 1678 занятий скопированы из таблицы **один раз** в приватный seed; после начальной загрузки Google Sheets не используется ни для чтения, ни для сохранения.
В публичном GitHub нет исходных записей, пароля, ключей и строки подключения.

Таблица остается отдельным архивом; все дальнейшие правки делаются в веб-дашборде.
