Как это работает

Новое занятие сразу считается посещенным: например, 45 минут = 0,75 часа. У уже записанных занятий отмеченное отсутствие сохраняется.

Сними галочку «Был», чтобы исключить пропущенное занятие из итогов. Введенные минуты при этом не теряются.

Напиши «Болел» в примечании любого занятия или дня — садовские часы не засчитаются; галочки занятий не сотрутся.

Сохранение: при входе через Google изменения записываются в общую таблицу и становятся доступны участникам с доступом к ней. Резервную JSON-копию можно скачать отдельно.

Общий дневник занятий

После входа ты увидишь занятия из общей Google-таблицы. Изменения минут, посещений и примечаний будут доступны другим участникам с правом редактирования.

Где получить Client ID

Как подключить один раз
  1. В Google Cloud создай OAuth Client ID типа Web application и включи Google Sheets API.
  2. В Authorized JavaScript origins добавь адрес этого сайта на Render, без завершающего слеша.
  3. В OAuth consent screen добавь участников как Test users, если приложение в режиме Testing.
  4. Убедись, что у каждого участника есть доступ к исходной Google-таблице. Этот сайт не обходит ее права.
  5. Вставь Client ID и войди. Кнопка «Поделиться» сформирует адрес с Client ID для семьи.
Данные ребенка не опубликованы в коде сайта. Сохранение происходит в Google Sheets с разрешения авторизованного пользователя.
